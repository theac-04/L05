# Changelog

1.0.0 (2023-10-05)
- Added a requirement for passwords to have at least 10 characters. Users need to ensure their passwords meet this new length requirement. (#1)
- Added validation to ensure emails contain both "@" and "." characters. Users need to make sure their email addresses include these characters. (#2)
- Updated the vowels counter to include both lowercase and uppercase vowels. Users may need to update their code to account for this change. (#3)
